HHermes Desktop Rust · Preview

Your Hermes.
A native Rust home.

Your sessions, tools, skills and plugins stay with Hermes.
This app connects to your existing workspace.

Uses your installed Hermes. No model changes, copied credentials or automatic installs.

Use a remote workspace

Sign in inside the workspace. Don’t paste tokens or passwords here.

Local setup & recovery

The Webapp must be enabled in your Hermes installation. This host never changes that setting for you.

If the local renderer is missing, build it, then open the workspace again. Building may download dependencies.

Runs hermes webapp --build-only. Closing this app never stops the shared gateway.
